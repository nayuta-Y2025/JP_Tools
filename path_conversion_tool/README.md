# Windows ⇄ Mac ファイルパス変換ツール

このツールは、Windows形式とMac形式のファイルパスを相互に変換するためのシンプルなWebアプリです。
特に、ファイルサーバーのUNCパス（例：`\\172.21.50.2\...`）とMacの `/Volumes/...` 形式の変換に対応しています。

## 🔧 機能

- Windows → Mac パス変換
- Mac → Windows パス変換
- UNCパス（`\\サーバー名\...`）の変換対応
- 日本語（カナ・濁音など）を含むパスにも対応（Mac→Win変換時にNFC正規化）
- 複数行の一括貼り付け・一括変換に対応
- 入力内容から Windows形式 / Mac形式 をリアルタイムで自動判別（バッジ表示）
- クリップボードへのコピー機能
- 「変換 → コピー → クリア」をワンクリックで実行する一括処理ボタン

## 💻 使い方

1. `index.html` をブラウザで開きます
2. テキストエリアに変換したいパスを貼り付けます（複数行可）
   - 入力すると上部のバッジが「Windows形式」または「Mac形式」を自動判別します
3. 用途に応じてボタンを使い分けます
   - **変換する**：入力内容を逆の形式に変換します
   - **コピー**：テキストエリアの内容をクリップボードにコピーします
   - **クリア**：テキストエリアを空にします
   - **変換 → コピー → クリア（一括）**：上記3つを一度に実行し、変換結果をコピーしたうえで入力欄を空にします（連続してパスを処理したい場合に便利）

## ⚠️ 制約事項

- Mac → Windows変換時、`/Volumes/...` 形式には元のサーバー名の情報が含まれないため、変換後のUNCパスは固定のサーバーアドレス（`172.21.50.2`）を使用します。別サーバーの場合は変換後にパスを手動で修正してください。
